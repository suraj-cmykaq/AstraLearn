# AstraLearn — Student Intelligence Platform

An interactive academic analytics platform that helps students understand their academic performance through data analysis, experimental machine learning, and personalised study recommendations.

## 🚀 Live Demo

[Launch AstraLearn](https://astralearn-axitjcxpzm6cgybrnrvbx8.streamlit.app/)

## ✨ Features

- **Academic Overview:** View class performance, averages, and key academic metrics.
- **Student Profiles:** Analyse individual student performance.
- **AI Risk Lab:** Explore experimental machine-learning-based academic risk analysis.
- **Study Recommendations:** Get subject-specific improvement suggestions.
- **What-If Simulator:** Explore how changes in marks affect overall performance.
- **Student Benchmarking:** Compare student performance with class-level results.
- **Academic Reports:** Generate and download performance reports.

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/suraj-cmykaq/AstraLearn.git
```

2. Open the project folder:

```bash
cd AstraLearn
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Launch the application:

```bash
streamlit run app.py
```

## 🎯 Project Objective

AstraLearn explores how academic data analytics and machine learning can support better academic decision-making. It aims to turn raw marks into understandable performance insights and actionable improvement suggestions.

## ⚠️ Disclaimer

The machine-learning risk analysis is experimental and intended for educational demonstration. It should not be treated as a validated prediction of a student's academic outcome.
